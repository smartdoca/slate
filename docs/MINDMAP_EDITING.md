# 思维导图工作区

## 方向与范围

以内容为中心的思维导图编辑器：浅灰画布、蓝色中心主题、按主分支继承的六色浅底节点与曲线连线。渲染、节点尺寸、间距与配色参考 aidcanvas 的 `runtime/thinking/scene.ts`，使用 LeaferJS 2.1.0 的 Frame / Text / Path。常用操作留在顶部，节点样式和全图设置收进右侧面板，缩放定位移到底部。参考 [XMind 的主题编辑约定](https://xmind.com/user-guide/topic-editing-new) 与[结构设置](https://xmind.com/user-guide/structure-new)，沿用项目的 Lucide 图标和中英文字典。

这是现有文档编辑器内的工作区改进，继续通过 Slate 保存、撤销文档操作和显示 SVG 预览。没有新增远程存储；新增与 aidcanvas 一致的 LeaferJS 2.1.0 及 viewport 依赖。未实现 XMind 的关系线、概要、边界、自由主题、演示、附件、原生 `.xmind` 文件导入等独立高级能力，因此不等同于 XMind 全功能复刻。

## 已实现

- 全屏工作区、导图 / 大纲切换、专注模式、主题计数、键盘帮助。
- 同级、前置同级、子主题、插入父主题；保留子主题删除；复制分支；右键菜单。
- 双击、空格、F2 或直接输入启动文字编辑；编辑时 Shift+Enter 换行、Esc 取消；支持输入法编辑。
- 方向键导航、Alt+上下调整同侧顺序、分支折叠 / 展开、拖拽整棵子树并调整层级。
- 完整树快照撤销 / 重做，包含文字、结构、配色和样式。
- 双向导图、向左 / 向右逻辑图；四组配色、纯色 / 点阵背景；节点形状、颜色、字号、加粗及应用到子树。
- 搜索包括被折叠的主题，定位时展开祖先；平移、20%–300% 缩放、实际大小、适应画布、回到中心。
- 带自定义树数据的复制粘贴；跨应用的缩进文本复制粘贴保留树层级；粘贴数据有深度、大小和节点数上限。
- 保存前提交正在编辑的内容、SVG 导出、保存失败保留数据、关闭前提示未保存修改、页面离开保护。
- 中英文界面使用相同的稳定英文 key；切换语言不重建图数据，也不翻译用户节点文字。

## 数据契约

`MindMapData` 新增可选字段，旧数据继续使用默认值：

```ts
structure?: 'balanced' | 'right' | 'left'
theme?: 'classic' | 'ocean' | 'forest' | 'mono'
background?: 'plain' | 'dots'
```

`MindMapNode` 新增 `fontSize?: number`、`bold?: boolean`；`style` 新增 `underline`。节点大小按实际字号、中英文宽度和多行内容估算；自动布局预留完整子树高度。预览版本为 7，旧预览在视图中重新生成，不会自动写回文档。

组件职责：`MindMapBlock.tsx` 处理 Slate、预览和只读行为；`MindMapWorkspace.tsx` 管理工作区与编辑会话；`mindmap.ts` 保存树操作；`mindmapGraph.ts` 生成共享场景几何和 SVG；`mindmapCanvas.ts` 维护 Leafer 原生图形。节点和连线按 ID 复用，平移只更新画布与浮动控件的变换，不读取逐节点 DOM。预览不创建隐藏编辑器；工作区按需加载，普通文档预览不加载 Leafer 运行时。

## 交互细节

| 操作 | 快捷键 |
| --- | --- |
| 子主题 / 后置同级 / 前置同级 | Tab / Enter / Shift+Enter |
| 插入父主题 | Ctrl/⌘+Enter |
| 编辑主题 / 编辑中换行 | Space 或 F2 / Shift+Enter |
| 导航 / 调整同侧顺序 | 方向键 / Alt+上下 |
| 折叠当前分支 | Ctrl/⌘+/ |
| 撤销 / 重做 | Ctrl/⌘+Z / Ctrl/⌘+Shift+Z 或 Ctrl+Y |
| 查找 / 保存 | Ctrl/⌘+F / Ctrl/⌘+S |
| 复制粘贴 / 删除 / 仅删除当前主题 | Ctrl/⌘+C、V / Delete / Ctrl/⌘+Delete |

新建或导航到视口外的主题时，只平移将它带入安全可视区所需的距离，保留缩放比例。窄屏默认收起格式面板，初次显示以中心主题居中，保持至少 85% 缩放；选中主题的加号始终显示，选中主题的折叠按钮也保留；低于 85% 时收起其他主题的折叠按钮。按钮尺寸与距节点边缘的间距使用固定屏幕像素，不随画布缩放。适应全部仍可作为整图概览操作。

## 创建行为

斜杠菜单、空白 Block 菜单和插入前后菜单共用创建逻辑。点击思维导图或流程图即打开对应编辑器；流程图没有默认节点或连线，思维导图只有一个中心主题。取消新建会移除未保存的占位块；保存后保留正常图示。自动打开意图仅存于当前编辑器的 WeakMap，不写入 Slate 节点、Yjs 或剪贴板，撤销恢复与远端投影不会重新弹出编辑器。空流程图可以保存，预览保留正常的空白画布尺寸。

## 节点按钮点击修复（2026-10-18）

通用按钮的 `:active` 位移动画曾覆盖节点加号和折叠按钮的定位变换，使鼠标按下后按钮移开原点击位置，松开时丢失 click。节点按钮现在保持命中区域不动，只对内部图标给按压反馈；鼠标/指针事件不再进入画布手势处理，新增主题输入框使用 `preventScroll` 聚焦，避免浏览器滚动画布容器。操作文案和原有视觉布局保留。

真实浏览器先复现原点击点无响应，修复后同一点正常新增。100%、150%、200% 缩放下，四角点击加号、减号和折叠数字共36项通过；另验证键盘折叠、折叠后新增及画布滚动偏移保持0。TypeScript通过，31项相关测试连续三轮31/31通过。局部自行复核，无独立评审。证据在 `test-results/mindmap-controls/`，包括 `report.json`、三轮日志、`click-feedback/record.mp4` 和操作前中后三帧。

## 节点指针与缩小操作（2026-10-18）

主题 Frame 设置原生 `cursor: pointer`，悬停节点时显示小手。选中主题的加号取消85%显示阈值，缩小后仍能直接新增子主题；折叠按钮在低缩放时仅显示于选中主题。控件以节点边缘为锚点，通过逆缩放保持加号23px、折叠按钮19px和两者之间7px的屏幕间距，缩放变化不再触发控件的位置过渡。保留上一轮固定命中区域与指针事件隔离修复。

实际浏览器验证20%、50%、80%、100%、200%、300%六档缩放：节点指针为pointer，加号尺寸23×23px，折叠与展开均正常，边缘点击新增成功。另验证50%时点击子主题后加号跟随并可新增。TypeScript通过，31项相关测试连续三轮31/31通过；局部自检，不新增动效或文案。证据在 `test-results/mindmap-zoom-controls/`，包括 `report.json`、三轮日志与 `half-scale/page.png`。
