# 思维导图工作区

## 方向与范围

以内容为中心的思维导图编辑器：浅暖画布、按主分支继承的配色、中心主题 / 主主题 / 子主题三级视觉层级。常用操作留在顶部，节点样式和全图设置收进右侧面板，缩放定位移到底部。参考 [XMind 的主题编辑约定](https://xmind.com/user-guide/topic-editing-new) 与[结构设置](https://xmind.com/user-guide/structure-new)，沿用项目的 Lucide 图标和中英文字典。

这是现有文档编辑器内的工作区改进，继续通过 Slate 保存、撤销文档操作和显示 SVG 预览。没有新增远程存储或依赖。未实现 XMind 的关系线、概要、边界、自由主题、演示、附件、原生 `.xmind` 文件导入等独立高级能力，因此不等同于 XMind 全功能复刻。

## 已实现

- 全屏工作区、导图 / 大纲切换、专注模式、主题计数、键盘帮助。
- 同级、前置同级、子主题、插入父主题；保留子主题删除；复制分支；右键菜单。
- 双击、空格、F2 或直接输入启动文字编辑；编辑时 Shift+Enter 换行、Esc 取消；支持输入法编辑。
- 方向键导航、Alt+上下调整同侧顺序、分支折叠 / 展开、拖拽整棵子树并调整层级。
- 完整树快照撤销 / 重做，包含文字、结构、配色和样式。
- 双向导图、向左 / 向右逻辑图；四组配色、纯色 / 点阵背景；节点形状、颜色、字号、加粗及应用到子树。
- 搜索包括被折叠的主题，定位时展开祖先；平移、20%–300% 缩放、实际大小、适应画布、回到中心。
- 带自定义树数据的复制粘贴；跨应用的缩进文本复制粘贴保留树层级；粘贴数据有深度、大小和节点数上限。
- 保存前提交正在编辑的内容、SVG 导出、保存失败保留数据、关闭前提示未保存修改、页面离开保护。
- 中英文界面使用相同的稳定英文 key；切换语言不重建图数据，也不翻译用户节点文字。

## 数据契约

`MindMapData` 新增可选字段，旧数据继续使用默认值：

```ts
structure?: 'balanced' | 'right' | 'left'
theme?: 'classic' | 'ocean' | 'forest' | 'mono'
background?: 'plain' | 'dots'
```

`MindMapNode` 新增 `fontSize?: number`、`bold?: boolean`；`style` 新增 `underline`。节点大小按实际字号、中英文宽度和多行内容估算；自动布局预留完整子树高度。预览版本升级为 6，旧预览会重新生成。

组件职责：`MindMapBlock.tsx` 处理 Slate、预览和只读行为；`MindMapWorkspace.tsx` 管理工作区与编辑会话；`mindmap.ts` 保存树操作；`mindmapGraph.ts` 统一工作区与预览的 X6 渲染和 SVG 导出。

## 交互细节

| 操作 | 快捷键 |
| --- | --- |
| 子主题 / 后置同级 / 前置同级 | Tab / Enter / Shift+Enter |
| 插入父主题 | Ctrl/⌘+Enter |
| 编辑主题 / 编辑中换行 | Space 或 F2 / Shift+Enter |
| 导航 / 调整同侧顺序 | 方向键 / Alt+上下 |
| 折叠当前分支 | Ctrl/⌘+/ |
| 撤销 / 重做 | Ctrl/⌘+Z / Ctrl/⌘+Shift+Z 或 Ctrl+Y |
| 查找 / 保存 | Ctrl/⌘+F / Ctrl/⌘+S |
| 复制粘贴 / 删除 / 仅删除当前主题 | Ctrl/⌘+C、V / Delete / Ctrl/⌘+Delete |

新建或导航到视口外的主题时，只平移将它带入安全可视区所需的距离，保留缩放比例。窄屏默认收起格式面板，初次显示保持至少 65% 缩放；低于 85% 隐藏节点旁的加号与折叠控件以避免遮挡，仍可使用顶部工具栏和键盘。适应全部仍可作为整图概览操作。
