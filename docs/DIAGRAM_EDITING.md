# Diagram and code block interactions

The flowchart workspace follows the light desktop layout of diagrams.net: a compact menu and icon toolbar, monochrome shape libraries, a white gridded page on a gray desktop, and contextual Style / Text / Arrange properties. The document preview remains an explicit action while editing. X6 still owns the native graph; the editor does not embed or send document data to diagrams.net.

- Double-click a node or edge to edit text in one compact input. Enter commits, Shift+Enter adds a line, and Escape cancels. Class/interface details remain separate from their heading.
- Select an edge to reveal endpoint, waypoint and segment handles. Drag to change the route. Alt+click adds a waypoint; double-click a waypoint removes it. Reset path restores automatic routing. A floating connector toolbar changes route or reverses direction beside the selected line. Route and marker menus show their actual line geometry. Line joins support sharp, round and bevel rendering; crossing straight/orthogonal connectors support arc, gap and cubic jumps with a size control. Boundary offsets apply to attached terminals and are disabled for free endpoints. Straight edges retain two endpoints.
- Automatic routing ignores background groups and free text. Connections meet the visible shape boundary, including when attached through hidden ports.
- The palette includes square-corner rectangles and filled block arrows. Block arrows support straight, single-bend and double-bend routes in all four directions while keeping their text upright. Drag the blue control point or use the bend slider to move the bend; shaft thickness, head size and border width have separate controls. Geometry is regenerated in actual node coordinates on resize, preserving the requested pixel thickness within the available bounds. Older straight arrows retain their proportions.
- Common elements include circles, ellipses, triangles, hexagons, pentagons, octagons, stars, crosses, clouds, servers, browsers and swimlanes. Click once to insert near an empty spot in the current viewport, or drag to place precisely. Circle resizing preserves its aspect ratio.
- Four quick-start combinations insert editable native nodes and edges: basic flow, conditional branch, application architecture and collaboration swimlane. Each insertion is one undoable action, with fresh cell IDs. Palette search includes template names and hints.
- Palette sections appear in this order: quick start, flowchart, UML, general, common elements.
- The mesh grid is initially visible and can be toggled independently of alignment snapping. Paper view, grid size, paper size/orientation, background, connection arrows/points, guides and minimap are configurable. White paper extends around negative and distant saved coordinates. Twelve style presets combine border, fill and text colors. Group headings sit at the top left.
- Rubber-band selection includes only elements fully contained in the selection rectangle.
- Select a shape or free-text node to rotate it with the rotation handle or enter an exact angle in the properties panel. Angles survive save/reopen, copy/paste and undo/redo. Rotated block-arrow bend handles continue to follow the arrow.
- In edit mode, the first image click selects it and another click opens the viewer. Clicking outside clears selection, so the next image click selects it again. Flowchart and mind-map clicks keep the element selected; their preview buttons open the viewer. Readonly viewing and attachment preview behavior remain available.
- Code blocks have a copy button and a keyboard-accessible language dropdown. The copy button displays only an icon. Copy includes the current code; success/failure is conveyed by the icon, color and tooltip, with an accessible status label. Readonly code can be copied, and cannot change language or accept Tab indentation.

## Document data

The existing schema and Yjs codec versions are unchanged. Optional diagram fields round-trip as part of the native diagram model:

- `DiagramNode.shape`: adds `'rectangle'`, `'block-arrow'`, `'circle'`, `'ellipse'`, `'triangle'`, `'hexagon'`, `'pentagon'`, `'octagon'`, `'star'`, `'cross'`, `'cloud'`, `'server'`, `'browser'` and `'swimlane'`.
- `DiagramNode.arrowDirection`: `'right' | 'down' | 'left' | 'up'`.
- `DiagramNode.arrowRoute`: `'straight' | 'elbow' | 'step'`.
- `DiagramNode.arrowThickness` / `arrowHeadSize`: requested shaft and arrowhead widths in pixels; rendered values are constrained by node dimensions.
- `DiagramNode.arrowBend`: bend position as a percentage.
- `DiagramNode.angle`: rotation in degrees; omission defaults to zero.
- `DiagramEdge.routeMode`: `'manual'`; omission uses automatic routing.
- `DiagramEdge.vertices`: waypoint coordinates `{ x, y }[]`.
- `DiagramEdge.sourceAnchor` / `targetAnchor`: a named X6 anchor with serializable arguments, e.g. `{ name: 'topLeft', args: { dx: '100%', dy: '50%', rotate: true } }`.


The modal canvas updates routes synchronously so segment handles never read a stale automatic route. Document preview generation remains asynchronous.

Keep terminal anchors with manual waypoints when applying diagram changes. Width-only document changes do not require a new SVG. Generated flow previews use preview version 9 so older rendered geometry and typography are regenerated.

## Draw.io workspace interactions (0.4.16)

- Selecting a shape exposes eight resize handles, a rotation handle and four directional connection arrows. Click an arrow to choose the next shape; drag it onto an existing shape to connect. Ctrl/⌘ click duplicates without a connector, and Shift click creates only a connector. The original twelve port IDs remain compatible with saved diagrams; ports display as small cross marks on hover.
- The right panel switches between drawing settings and selected-object properties. Shape properties include fill, border, opacity, rounded corners, shadow, font family/size/weight/style/alignment, exact width/height/position/angle and aspect-ratio locking. Shared properties apply to multi-selection in one history batch. Arrange supports layer order, alignment, equal spacing, grouping and ungrouping.
- Connectors expose independent start/end markers, separate start/end arrowhead sizes and boundary offsets, line width/dash/route, label font/color/style and label position. Selecting a connector exposes small endpoint, waypoint and segment handles. Manual orthogonal routes keep their waypoints while adding necessary right angles when a terminal moves or is reconnected. Reset path restores automatic routing. A floating connector toolbar changes route or reverses direction beside the selected line. Route and marker menus show their actual line geometry. Line joins support sharp, round and bevel rendering; crossing straight/orthogonal connectors support arc, gap and cubic jumps with a size control. Boundary offsets apply to attached terminals and are disabled for free endpoints.
- Ordinary grouping adds no visible border; explicitly inserted background containers keep their own style. Groups move, resize and rotate their descendants and embedded manual routes together. A normal child click selects the group; Ctrl/⌘ click selects inside it. Shift click toggles selection. Ungrouping detaches children without deleting them. Clipboard fragments remap both node/edge parents and terminal IDs before pasting; copying through the native keyboard clipboard survives closing and reopening the editor.
- F2/Enter or double-click edits text in place. Arrow keys move by one point, Shift+arrows by ten. Space+drag, middle-button drag and the hand tool pan; Ctrl/⌘+wheel zooms. Menus support keyboard navigation. Tab stays inside the editor, including secondary dialogs. Initial page fitting avoids a gray strip above short diagrams, and save/reopen restores the viewport center and zoom. Unsaved close offers keep editing, discard or save; export/commit errors retain the graph and offer retry.
- General stencils also include cube, chevron, trapezoid, callout, folder and crescent shapes. Rounded rectangle and bent-arrow presets retain their geometry when inserted by either click or drag. Library search and the More shapes dialog operate on the native stencil groups.

New optional document fields are `FlowchartElement.canvasSettings`, node font/effect/alignment/aspect fields and edge parent/marker-size/offset/font/label-position fields. Canvas settings include the last saved viewport center and zoom. Schema and Yjs codec versions are unchanged. Save updates the editor document; persistence and durable-save acknowledgement remain host responsibilities. The header does not claim remote storage success.

This is alignment of the native flowchart workspace and its core editing interactions. The complete diagrams.net stencil catalog, its file format/importer, gradients and every advanced formatting command are not provided.
